Project Overview:
This project focuses on analyzing retail sales data using Microsoft Power BI. An interactive dashboard was developed to transform raw sales data into meaningful business insights and support data-driven decision-making.

Key Features:
•	Interactive KPI cards for important business metrics.
•	Sales and profit analysis.
•	Product and category performance analysis.
•	Regional sales comparison.
•	Time-based sales trend visualization.
•	Interactive slicers for dynamic filtering.

Tools & Technologies:
•	Microsoft Power BI
•	Power Query
•	DAX
•	Data Cleaning and Transformation
•	Data Visualization

Outcome:
Created an interactive retail sales dashboard that converts raw sales data into meaningful visual insights, helping users understand business performance and identify sales trends.
